# 用户中心 对外契约（detail/api/用户中心.md）

status: active
所属域: 平台底座　维护者: 协调者侧　父文档: [../../design.md](../../design.md)

> 前缀 `users`；五类角色档案 + 账号生命周期 + 家长-学生绑定（多对多，data-ownership 归底座用户中心）。

## 1. 端点清单

| 方法与路径 | 语义 | 权限 |
|---|---|---|
| GET `/users` | 档案检索（分页；按角色类型/组织/姓名/状态过滤；敏感字段脱敏返回） | `user:read` |
| GET/POST `/users`；POST `/users/{id}`；PATCH `/users/{id}` | 档案详情 / 创建 / 更新 | `user:write` |
| POST `/users:import` | Excel 批量导入（**一期为同步版**：学校百级规模直接返回行级结果报告；异步任务化随规模需求升级——实现标注 2026-09-09） | `user:import` |
| GET `/users/import-tasks/{taskId}` | 导入任务进度与结果报告（**随异步化交付，一期不适用**） | `user:import` |
| POST `/users/{id}/status` | 生命周期动作：activate / disable / reset-password | `user:lifecycle` |
| GET `/users/{id}/guardians` | 学生的家长绑定列表 | `user:read` |
| POST `/guardian-bindings` | 发起绑定（家长手机号 + 学生学籍号匹配，生成待确认记录） | `user:bind:write` |
| PATCH `/guardian-bindings/{id}` | 确认 / 解绑（确认须家长侧操作或持确认码） | 见约定 |

## 2. 关键约定

- **合规红线**（core §7）：学生敏感字段（姓名/身份证/学籍号）加密存储、接口默认脱敏返回，明文仅授权端点按需返回并落审计；收集学生信息以监护人确认为前提
- **加密与检索分离**：手机号/学籍号等值查询走 HMAC-SHA256 哈希列（`phone_hash`/`student_no_hash`，独立密钥），加密列只负责解密展示（随机 IV 密文不可比较）
- **更新语义**：PATCH 字段 null=保留（漏传不清空存量）；导入单行原子（建档+入班同事务），重放同一文件按学籍号哈希唯一键去重报 USER-007，不产生重复数据
- **绑定语义**：`guardian_student.status = confirmed` 后家校域方可触达该家长；解绑立即生效并通知家校域（事件 `user.guardian-binding-changed`）
- 账号创建：建档即开户（初始密码随机/重置），disable 即拒登并撤销全部 refresh

## 3. 错误码（USER）

| 码 | 语义 |
|---|---|
| USER-001 | 档案不存在 |
| USER-002 | 手机号已被其他账号占用 |
| USER-003 | 学生档案不存在或非学生（绑定场景） |
| USER-004 | 绑定记录不存在或已解绑 |
| USER-005 | 导入文件格式/模板错误 |
| USER-006 | 导入行校验失败（返回行号与原因明细） |
| USER-007 | 学籍号已被其他学生占用（含重复导入去重） |
| USER-008 | 登录名已被占用 |
