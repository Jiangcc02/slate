# 组织架构 对外契约（detail/api/组织架构.md）

status: active
所属域: 平台底座　维护者: 协调者侧　父文档: [../../design.md](../../design.md)

> 前缀 `orgs`；班级实体与名单归底座，班级的教学使用（排课）归教务域（data-ownership）。

## 1. 端点清单

| 方法与路径 | 语义 | 权限 |
|---|---|---|
| GET `/orgs/tree` | 组织树（五级：campus/section/grade/class），可按类型/学年过滤 | 登录即可 |
| POST `/orgs`；PATCH/DELETE `/orgs/{id}` | 节点管理（删除须无子节点且班级须已无在籍名单） | `sys:org:*` |
| GET `/orgs/{id}/members` | 班级在籍名单（分页，含学生档案摘要） | `org:member:read` |
| POST `/orgs/{id}/members` / DELETE `/orgs/{id}/members/{studentId}` | 入班 / 出班（异动留痕，出班须带原因） | `org:member:write` |
| GET/POST `/orgs/{id}/teaching-assignments`；DELETE `…/{assignmentId}` | 班级任课关系管理（教师×课程×学年学期） | `org:teaching:*` |
| GET `/orgs/teaching-assignments?teacherId=&term=` | 按教师查询任课（教师端工作台入口） | 登录即可 |

## 2. 关键约定

- 任课关系中的 `courseId` 引用课程域 ID，只存 ID 不复制字段（global-data-model §4）
- 班级名单变更外发领域事件：`org.class.member-changed`（outbox），学情/教务等消费方订阅

## 3. 错误码（ORG）

| 码 | 语义 |
|---|---|
| ORG-001 | 组织节点存在子节点，不可删除 |
| ORG-002 | 班级仍有在籍学生，不可删除 |
| ORG-003 | 同一学生同学年同学级已有在籍记录 |
| ORG-004 | 任课关系重复（同教师×班级×课程×学期） |
| ORG-005 | 引用的教师/课程/学年学期不存在或无效 |
| ORG-006 | 上级节点无效或层级不符（五级链：机构→校区→学部→年级→班级；实现新增，2026-09-09） |
