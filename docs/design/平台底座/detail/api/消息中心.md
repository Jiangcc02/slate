# 消息中心 对外契约（detail/api/消息中心.md）

status: active
所属域: 平台底座　维护者: 协调者侧　父文档: [../../design.md](../../design.md)

> 前缀 `messages`；底座管投递通道，定向触达的业务规则（发给谁、何时发）归家校协同域（data-ownership 仲裁）。

## 1. 端点清单

| 方法与路径 | 语义 | 权限 |
|---|---|---|
| GET `/messages/inbox` | 我的站内信收件箱（分页；unreadOnly 过滤） | 登录即可 |
| PATCH `/messages/{id}/read` | 标记已读（单条） | 收件人 |
| PATCH `/messages/read-all` | 全部已读 | 登录即可 |
| GET `/messages/unread-count` | 未读数（轮询端点，前端顶栏） | 登录即可 |
| POST `/messages` | 发站内信（服务间/域内调用为主：收件人集合 + 标题 + 正文 + 跳转引用） | 见约定 |
| GET/POST `/announcements`；PATCH/DELETE `/announcements/{id}` | 公告管理（范围：全校/校区/学部/年级/班级；发布/下架） | `msg:announcement:*` |
| GET `/announcements` | 公告列表（按范围可见性过滤，登录即可） | 登录即可 |

## 2. 关键约定

- **面向用户的定向触达**（成绩发布通知等）由各业务域经内部接口投递，投递记录落 `message_delivery`；对外部渠道（邮件/短信/微信）一期只留 `notify_channel_config` 与适配器接口，不实现渠道对接
- 公告按组织范围可见：范围值引用 orgs 树节点 ID；不复制组织数据
- WebSocket 实时推送一期不做，收件箱靠轮询（`unread-count`，建议 60s）

## 3. 错误码（MSG）

| 码 | 语义 |
|---|---|
| MSG-001 | 消息不存在或无权访问 |
| MSG-002 | 公告范围节点无效 |
| MSG-003 | 收件人集合为空或含无效账号 |
