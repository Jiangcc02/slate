# 系统管理 对外契约（detail/api/系统管理.md）

status: active
所属域: 平台底座　维护者: 协调者侧　父文档: [../../design.md](../../design.md)

> 前缀 `sys`；数据字典、参数配置、日志查询；Knife4j 接口文档聚合挂 boot。

## 1. 端点清单

| 方法与路径 | 语义 | 权限 |
|---|---|---|
| GET `/sys/dicts/{type}` | 字典项查询（公开给全部登录用户；Redis 缓存） | 登录即可 |
| GET/POST `/sys/dicts`；POST `/sys/dicts/{type}/items`；DELETE `/sys/dicts/items/{id}` | 字典类型与项管理（项为 upsert 语义；变更即失效缓存；删除即物理删除，审计留痕） | `sys:dict:*` |
| GET `/sys/configs/{key}` | 参数读取（登录即可；scope=GLOBAL/CAMPUS，CAMPUS 未命中回落 GLOBAL；两级均未命中 SYS-004；敏感参数不在此返回） | 登录即可 |
| GET/POST `/sys/configs`；DELETE `/sys/configs/{id}` | 参数管理（POST 为 upsert；作用域：全局/校区；删除即物理删除） | `sys:config:*` |
| GET `/sys/login-logs` | 登录日志查询（分页；账号/时间范围过滤，时间缺省时默认最近 30 天） | `sys:log:read` |
| GET `/sys/operation-logs` | 操作日志查询（分页；账号/traceId/时间范围过滤，时间缺省时默认最近 30 天） | `sys:log:read` |

## 2. 关键约定

- **日志只读**：login_log / operation_log 只追加（data-ownership），不提供修改与删除 API；操作日志参数摘要已脱敏
- 字典语义候选：学段、学期、科目、学期周次、通知渠道类型、文件 bizType——随各域实现任务包登记新类型，不在契约预列全
- Knife4j：`/doc.html` 聚合全部模块接口，仅 dev/test profile 开放（生产关闭）

## 3. 错误码（SYS）

| 码 | 语义 |
|---|---|
| SYS-001 | 参数校验失败（框架兜底，见 slate-framework SysErrorCode） |
| SYS-002 | 请求方式或媒体类型不支持 |
| SYS-003 | 字典类型不存在 |
| SYS-004 | 参数键不存在或作用域冲突 |
| SYS-999 | 系统内部错误（框架兜底） |
