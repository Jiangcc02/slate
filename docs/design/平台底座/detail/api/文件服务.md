# 文件服务 对外契约（detail/api/文件服务.md）

status: active
所属域: 平台底座　维护者: 协调者侧　父文档: [../../design.md](../../design.md)

> 前缀 `files`；MinIO（S3 协议）起步，存储层抽象可替换云 OSS；元数据归底座，业务引用只存 fileObjectId。

## 1. 端点清单

| 方法与路径 | 语义 | 权限 |
|---|---|---|
| POST `/files/upload-credentials` | 申请预签名上传（入参：bizType、文件名、大小、ContentType；出参：objectKey + 预签名 PUT URL + 过期时间） | 登录即可（配额内） |
| POST `/files` | 登记元数据（预签名上传完成后回调登记，绑定 bizType+bizId；返回 fileObjectId） | 登录即可 |
| GET `/files/{id}/download-url` | 取预签名下载 URL（private，15min；仅上传者或 `file:manage` 管理员，无权与不存在同码 FILE-001；业务域分享规则随 bizType 归属接入） | 上传者/`file:manage` |
| GET `/files` | 元数据检索（按 bizType/bizId/上传者过滤，分页） | `file:manage` |
| DELETE `/files/{id}` | 删除（引用中禁止；逻辑删 + 对象异步清理） | 上传者或 `file:manage` |

## 2. 关键约定

- **上传流**：客户端直传 MinIO（预签名 URL），文件字节流不经过业务单体；上传完成后客户端持 objectKey 登记，未登记的对象由清理任务回收（孤儿对象，24h）
- **类型白名单与配额**：按 bizType 配置（课件 pptx/pdf/html、图片 jpg/png/webp、视频 mp4 上限 2GB）；另有每用户每日预签名签发配额（`slate.files.daily-upload-quota`，默认 200），超限拒绝 `FILE-003`
- **登记核验**：register 以 MinIO statObject 实测大小为准（客户端自报 sizeBytes 不落库）；上传凭证绑定签发人与业务类型，登记成功即消费（一次性）
- 视频转码/点播不自建（蓝图 §十三）：一期只存原片，播放能力随教室端/课程域任务包评估外挂

## 3. 错误码（FILE）

| 码 | 语义 |
|---|---|
| FILE-001 | 文件不存在、已删除或无权访问 |
| FILE-002 | 文件类型不在白名单 |
| FILE-003 | 文件大小超限或配额用尽 |
| FILE-004 | 文件被业务引用中，非管理员禁止删除（管理员可强制删） |
| FILE-005 | objectKey 登记不一致（预签名与登记不匹配） |
