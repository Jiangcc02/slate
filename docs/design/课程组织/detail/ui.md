# 课程组织 界面草案（detail/ui.md）

status: draft
所属域: 课程　维护者: agent-codex　父文档: [../design.md](../design.md)

> 本文件是**线框级草案**，不是组件规格；页面实现随本域实现任务包交付（[frontend/AGENTS.md](../../../../frontend/AGENTS.md)）。
> 契约与错误码见 [api.md](api.md)，实体与字段可变性见 [data.md](data.md)。

## 1. 涉及端的推导

依据 [总纲 §四 角色 × 域 交叉矩阵](../../../product/K12教育系统.md) 的「课程」行：

| 端 | 矩阵取值 | 是否涉及 | 落位 |
|---|---|---|---|
| 学生端 | — | 否 | 学生不直接面对课程档案：课程经由教学班与学习中心触达（学习域 #9 学习中心，尚未成文） |
| 家长端 | — | 否 | 家长只看学情，不涉及课程维护 |
| 教师 / 班主任 | 建课备课 | **是** | `frontend/apps/admin`（管理端，教师角色） |
| 教务 | 审核上架 | **是** | `frontend/apps/admin`（管理端，教务角色） |
| 管理员 | — | 否 | 管理员只管底座与字典权限，不在此维护业务课程 |
| 教室端 | 不在矩阵内 | 否 | 教室端消费的是**课时上的课件**（课件管理包 + 教室端专题，四期），不直接读课程档案 |

结论：本包界面**全部落在 `apps/admin` 一个应用**，按角色（教师 / 教务）分组菜单——与 [frontend/AGENTS.md](../../../../frontend/AGENTS.md)「管理端 = 教师/教务/管理员/校长端」一致。

## 2. 页面清单

| # | 页面 | 路由（建议） | 使用角色 | 依托契约 |
|---|---|---|---|---|
| P1 | 我的课程 | `/courses` | 教师 | `GET /courses` |
| P2 | 建课向导 | `/courses/new` | 教师 | `GET /courses/subject-stage-scopes`、`GET /courses/textbook-editions`、`POST /courses` |
| P3 | 课程详情与编辑 | `/courses/:id` | 教师 | `GET/PATCH /courses/{id}`、`POST …/submit`、`POST …/disable` |
| P4 | 课程审核队列 | `/course-reviews` | 教务 | `GET /courses?status=PENDING_REVIEW`、`POST …/approve`、`POST …/reject` |
| P5 | 教材版本维护 | `/course-settings/textbook-editions` | 教务 | `GET/POST/PATCH/DELETE /courses/textbook-editions` |
| P6 | 学科-学段适用关系 | `/course-settings/subject-stage-scopes` | 教务 | `GET/POST/PATCH/DELETE /courses/subject-stage-scopes` |

学段、学科的**字典项本身**不在本模块维护（走底座系统管理页面，`sys:dict:*` 权限）——本模块只提供 P6 这张"哪些学科在哪些学段开设"的业务关系表。

## 3. 线框级说明

### P1 我的课程 `/courses`

```
┌ 我的课程 ────────────────────────────────── [＋ 新建课程] ┐
│ 学段[全部▾] 学科[全部▾] 教材版本[全部▾] 状态[全部▾] 🔍[      ] │
├──────────────────────────────────────────────────────────┤
│ 课程名        │ 学段 │ 学科 │ 教材版本      │ 状态   │ 操作   │
│ 高一数学必修一 │ 高中 │ 数学 │ 人教版(2019) │ 已上架 │ 查看   │
│ 初二物理力学   │ 初中 │ 物理 │ 人教版       │ 待审核 │ 查看   │
│ 小学科学三上   │ 小学 │ 科学 │ 教科版       │ 草稿   │ 编辑…  │
├──────────────────────────────────────────────────────────┤
│                                     ‹ 1 2 3 ›  共 47 条    │
└──────────────────────────────────────────────────────────┘
```

- 三维列展示**字典 label**（前端按 `GET /sys/dicts/{type}` 映射 code → 展示名，不硬编码）
- 状态用标签色区分：草稿（灰）/ 待审核（橙）/ 已上架（绿）/ 已停用（灰删线）
- 过滤参数平铺在 query，与 [api.md §3](api.md) 一致；分页走 `page/size`
- 行内「操作」按状态收敛：`DRAFT` → 编辑 / 提交审核 / 停用；`PUBLISHED` → 查看 / 停用（[data.md §4.1](data.md)）

### P2 建课向导 `/courses/new`

```
┌ 新建课程 ────────────────────────────────────────────────┐
│ ① 学段  [小学] [初中] [高中]        ← 单选卡片              │
│ ② 学科  [语文][数学][英语][物理][化学] …                    │
│         （仅列出所选学段"已开设"的学科，见下方联动说明）      │
│ ③ 教材版本  学段/学科已定 → [人教版(2019) ▾]                │
│            （仅列出该三维下已启用的版本）                    │
│ ─────────────────────────────────────────────────────── │
│ 课程名 *  [                          ]                     │
│ 课程简介  [                                            ]    │
│ 封面      [选择文件]                                       │
│                                  [取消]  [创建为草稿]       │
└──────────────────────────────────────────────────────────┘
```

联动说明（前端必须做，后端仍兜底校验）：

1. 选学段 → 用 `GET /courses/subject-stage-scopes?stageCode=…&enabled=true` 过滤学科候选；不可用学科**不出现**，避免用户走到 `CRS-002`
2. 选完学段+学科 → 用 `GET /courses/textbook-editions?stageCode=…&subjectCode=…&status=ENABLED` 取版本候选；空列表时提示"该三维尚未维护教材版本，请先联系教务维护"（对应 `CRS-004` 的前置提示）
3. 改名/改三维使提交失败时，按 §4 映射表就近定位到出错的步骤

### P3 课程详情与编辑 `/courses/:id`

```
┌ 高一数学必修一            [状态: 已上架] ─────────────────┐
│ 三维归属 学段 高中 │ 学科 数学 │ 教材版本 人教版(2019) 🔒  │
│ 课程简介 …                                               │
│ 封面     [缩略图]                                        │
│ ─────────────────────────────────────────────────────── │
│ 创建 张三 2026-09-10 10:00 ／ 最近修改 李四 2026-09-11 09:00│
├──────────────────────────────────────────────────────────┤
│ [保存] [提交审核] [停用课程]     ← 按钮按状态与权限显隐      │
└──────────────────────────────────────────────────────────┘
```

- **三维锁定**：`PUBLISHED` 时三维字段只读并挂锁图标，旁注"已上架课程的三维归属不可变更；如需调整请停用后新建"（`CRS-007`）
- `DISABLED` 时全表单只读，底部按钮区替换为"该课程已停用（终态）"
- **停用二次确认**弹窗必须写清 [../design.md](../design.md) §3.4 的三条承诺：既有教学班与学习记录不受影响、不再允许新的引用、**停用不可撤销**

### P4 课程审核队列 `/course-reviews`（教务）

```
┌ 课程审核 ────────────────────────────────────────────────┐
│ 学段[全部▾] 学科[全部▾]             共 6 门待审核          │
├──────────────────────────────────────────────────────────┤
│ ☐ 课程名         │ 三维归属              │ 提交人 │ 提交时间 │
│ ☐ 初二物理力学   │ 初中·物理·人教版      │ 张三   │ 09-11   │
│ ☐ 小学科学三上   │ 小学·科学·教科版      │ 王五   │ 09-11   │
├──────────────────────────────────────────────────────────┤
│ [批量通过] [批量驳回]        ← 逐条也各有一组操作按钮       │
└──────────────────────────────────────────────────────────┘
```

- 驳回必须填理由（驳回理由进操作审计；当前契约未定义"驳回理由"字段，实现期如确需落库，走**中档**文档同步，不新增契约端点）
- 审核操作权限 `course:course:review`，教师在 P4 不可见（菜单按权限渲染）

### P5 教材版本维护 `/course-settings/textbook-editions`（教务）

```
┌ 教材版本 ─────────────────────────────────── [＋ 新建版本] ┐
│ 学段[全部▾] 学科[全部▾] 状态[启用▾]                        │
├──────────────────────────────────────────────────────────┤
│ 学段 │ 学科 │ 出版社         │ 版本名   │ 修订年 │ 状态 │ 操作│
│ 高中 │ 数学 │ 人民教育出版社 │ 人教版   │ 2019  │ 启用 │ …  │
│ 初中 │ 物理 │ 人民教育出版社 │ 人教版   │ 0     │ 启用 │ …  │
├──────────────────────────────────────────────────────────┤
│ 说明：身份字段（学段/学科/出版社/版本名/修订年）创建后不可修改 │
└──────────────────────────────────────────────────────────┘
```

- 新建表单的五个身份字段创建后置灰（[data.md §2.2](data.md)）
- 「删除」仅在未被课程引用时可用，被引用时置灰并提示"该版本已被 N 门课程使用，请改为停用"（`CRS-009`）
- 修订年未填 → 存 `0`，列表显示「—」（[data.md §7](data.md) 唯一索引约束）

### P6 学科-学段适用关系 `/course-settings/subject-stage-scopes`（教务）

矩阵式勾选，一屏看清"哪个学段开哪些学科"：

```
┌ 学科 × 学段 适用关系 ────────────────────────────────────┐
│           │ 小学 │ 初中 │ 高中 │                          │
│ 语文      │  ☑   │  ☑   │  ☑   │                          │
│ 数学      │  ☑   │  ☑   │  ☑   │   勾选/取消即时提交        │
│ 科学      │  ☑   │  ☑   │  ☐   │   （POST/PATCH/DELETE）   │
│ 物理      │  ☐   │  ☑   │  ☑   │                          │
│ 化学      │  ☐   │  ☑   │  ☑   │                          │
├──────────────────────────────────────────────────────────┤
│ ⚠ 取消已被课程使用的组合将被拒绝（CRS-012）                 │
└──────────────────────────────────────────────────────────┘
```

- 取消勾选已开课的（学段×学科）→ 后端 `CRS-012`，前端回滚勾选并提示先处理相关课程
- 该页面是 `CRS-002` 的**唯一治理入口**：矩阵越贴近真实教学计划，教师建课越少踩坑

## 4. 错误码 → 界面反馈映射

| 错误码 | 界面反馈位置与文案方向 |
|---|---|
| `CRS-001` | 课程名输入框下红字「该三维下已有同名课程」 |
| `CRS-002` | P2 第 ② 步高亮「该学科不在本学段开设，请先在适用关系中启用」；P6 治理 |
| `CRS-003` | 表单顶部提示「学段/学科字典项无效，请联系管理员检查字典」 |
| `CRS-004` | P2 第 ③ 步高亮「教材版本不存在或已停用」 |
| `CRS-005` | P2 第 ③ 步高亮「该教材版本不属于所选学段/学科」 |
| `CRS-006` | 操作按钮**不应出现**（按状态显隐）；出现即前端状态过期，提示刷新 |
| `CRS-007` | 三维字段旁锁图标说明「已上架不可改，请停用后新建」 |
| `CRS-008` | P5 新建表单提示「同学段同学科同社同名同修订年的版本已存在」 |
| `CRS-009` | P5 删除按钮提示「已被课程使用，请改为停用」 |
| `CRS-010` | 跨域引用场景，界面不直接暴露；日志与 traceId 定位 |
| `CRS-011` / `CRS-012` | P6 勾选回滚 + 说明原因 |
| `CRS-013` | 提示「课程已被他人修改，请刷新后重试」 |

原则：**前端只做引导，不做最终判定**——所有联动过滤都是体验优化，最终校验与错误码一律以后端为准（[api.md §2](api.md) 的固定校验顺序）。

## 5. 前端落地约定

- 三个端（管理端 / 学生端 / 教室端）主题令牌一致；本包只涉及 `apps/admin`
- 组件用 shadcn-vue 源码模式按需引入；**禁止整包组件库**；图标用 lucide-vue-next（[frontend/AGENTS.md](../../../../frontend/AGENTS.md)）
- 契约类型与 HTTP 客户端复用 `packages/shared`；课程相关类型随实现任务包加入该包，不在应用内私建副本
- 所有 `.ts` / `.vue` 文件带 L1 文件头（CI 强制）
