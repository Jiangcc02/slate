# 蓝图：家校协同

status: draft

> K12 特色域：家长是一等公民（总纲 §三），家校共育闭环（总纲 §八-4）的载体。排期：**三期**（家长完整体验依赖二期成绩数据，与学情预警同期成型）。

## 本域要什么（模块清单）

| 模块 | 优先级 | 依赖 | 状态 |
|---|---|---|---|
| 通知公告：按班级/年级定向触达家长 | 三期 | 底座绑定关系、消息中心 | 未开始 |
| 请假审批：家长发起 → 班主任审批 | 三期 | 底座绑定关系 | 未开始 |
| 家校沟通记录 | 三期 | 底座绑定关系 | 未开始 |
| 家长会管理 | 三期 | 组织架构 | 未开始 |
| 学习报告自动推送：每周/每学期（Agent 建设期由 AI 生成，走分层确认） | Agent 建设期 | 学情域、底座消息 | 未开始 |

## 本域的成功画面

家校共育闭环跑通：课堂表现/成绩/预警自动推家长 → 家长督促反馈 → 教师掌握家庭侧情况 → 调整教学。家长是闭环的参与者，不是旁观者。

## 接缝与约束

- 定向触达的业务规则（谁能给谁的家长发什么）属本域；投递通道（站内信/外渠）属底座消息中心（[data-ownership](../../architecture/contracts/data-ownership.md)）
- 依赖底座家长-学生绑定（多对多）——从招生/入学建立，贯穿缴费、通知、报告所有场景
- 面向家长/学生的定向触达是**高风险动作**：Agent 产出须经确认门（铁律 L8）
