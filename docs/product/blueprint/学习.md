# 蓝图：学习（学）

status: draft

> 学生的学习过程载体。注意本域与测评域的**作业两流边界**（2026-09-09 仲裁，见 [data-ownership](../../architecture/contracts/data-ownership.md)）：任务流（布置/提交状态/打回）归本域，答题流（答题/判分/成绩）归测评域。

## 本域要什么（模块清单）

| 模块 | 优先级 | 依赖 | 状态 |
|---|---|---|---|
| 学习中心：在学课程、继续学习、完成进度 | 一期 | 课程域开班 | 未开始 |
| 学习行为记录：播放进度、防挂机、笔记、收藏 | 一期 | 学习中心 | 未开始 |
| 作业闭环·任务流：布置 → 提交状态 → 打回重做（答题与判分在测评域） | 一期 | 课程域课时、测评域答题流 | 未开始 |
| 答疑讨论：提问、回答、讨论 | 未排期 | 学习中心 | 未开始 |
| 课堂互动参与记录：点名/抢答等随堂参与数据 | 四期（随教室端） | 教室端专题 | 未开始 |

## 本域的成功画面

学生主流程中段（总纲 §七）：进入学习中心 → 逐课时学习（记笔记、提问）→ 交作业 → 查批改结果 → 重做。学习记录沉淀为学情域的过程数据源。

## 接缝与约束

- 作业两流拆分是本域最大接缝：本域管"谁在什么时候要对谁交什么"，测评域管"交上来的答题对不对得多少分"——两域设计文档须共同引用同一条仲裁
- 学习记录（含课堂互动参与）属主在本域；学情域经契约消费（[data-ownership](../../architecture/contracts/data-ownership.md)）
- 学生"看批改结果"读测评域成绩接口，不在本域复制
