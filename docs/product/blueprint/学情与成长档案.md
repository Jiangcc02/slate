# 蓝图：学情与成长档案（评）

status: draft

> 评的载体，三期能洞察的主力域。全部数据是衍生数据：源数据归源域（测评、学习），本域只拥有画像、档案与预警。

## 本域要什么（模块清单）

| 模块 | 优先级 | 依赖 | 状态 |
|---|---|---|---|
| 学情分析：知识点掌握度雷达、班级/年级对比、薄弱定位 | 三期 | 测评成绩、学习记录（契约消费） | 未开始 |
| 学生画像：学生侧个性化洞察 | 三期 | 学情分析 | 未开始 |
| 学业预警：进度落后/成绩下滑 → 自动推教师和家长 | 三期 | 学情分析、底座消息、家校触达 | 未开始 |
| 学生成长档案（K12 特色）：综合素质记录、奖惩、德育积分、教师评语——过程性数据长期沉淀 | 三期 | 底座 | 未开始 |
| 评教（教学评价） | 三期 | 归属可在设计期再裁（教务教学质量 vs 本域） | 未开始 |

## 本域的成功画面

教学质量闭环（总纲 §八-1）的数据枢纽：教→学→练→测的数据汇成学情，反哺教学调整；家长看到的孩子报告、教师看到的班级薄弱、班主任收到的预警都出自本域。学生成长闭环（§八-2）的"针对性补弱"依据也在这里。

Agent 建设期增量：学情周报自动生成（AI 产出走分层确认，宪法 §1）。

## 接缝与约束

- 源数据归源域：本域不落副本，经契约接口实时消费（[data-ownership](../../architecture/contracts/data-ownership.md)、[global-data-model](../../architecture/contracts/global-data-model.md)）
- 预警触达走底座消息通道 + 家校域定向规则，本域不建投递
- 成长档案含未成年人敏感信息：加密存储、展示脱敏、导出留痕（总纲 §十二）
