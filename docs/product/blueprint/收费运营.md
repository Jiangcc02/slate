# 蓝图：收费运营（营）

status: draft

> 机构现金流（招生-交付-口碑闭环的出口，总纲 §八-5）；公立形态裁剪为代收费务（宪法 §1）。排期：四期（按定位选配）。

## 本域要什么（模块清单）

| 模块 | 优先级 | 依赖 | 状态 |
|---|---|---|---|
| 学费账单：按班/按期生成 | 四期（按定位） | 开班、底座绑定关系 | 未开始 |
| 在线缴费 | 四期（按定位） | 账单 | 未开始 |
| 退费 | 四期（按定位） | 缴费记录 | 未开始 |
| 续费提醒 | 四期（按定位） | 缴费记录、底座消息 | 未开始 |

## 本域的成功画面

家长端缴费体验闭环：查账单 → 在线缴 → 可退费；机构的续费提醒驱动口碑闭环反哺招生。

## 接缝与约束

- 账单与缴费/退费记录属主在本域（[data-ownership](../../architecture/contracts/data-ownership.md)）
- 计费对象（学员）经底座绑定关系确定；缴费是**高风险动作**，Agent 期同样过确认门（铁律 L8）
- 公立裁剪形态：只保留代收费务
