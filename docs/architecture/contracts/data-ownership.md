# 数据所有权

status: v1.0（冻结，2026-09-09，底座设计落地即冻结；新增实体随各域设计登记，归属仲裁依旧走本文件）

> 每个数据实体只能有一个拥有域；拥有域之外的访问必须走契约接口（铁律 L4）。
> 本文件是跨域冲突仲裁的权威依据（见 `guides/design-guide.md` §7）。

## 所有权清单

| 数据实体 | 拥有域 | 说明 |
|---|---|---|
| 账号与凭证、登录/操作日志 | 平台底座 | 用户中心与审计；日志只追加不修改 |
| 角色与权限（RBAC） | 平台底座 | 到菜单/按钮级 |
| 组织架构（机构→校区→学部→年级→班级）与班级学生名单 | 平台底座 | 班级实体与名单归底座；班级的教学使用（排课）归教务 |
| 教师-班级-课程任课关系 | 平台底座 | 蓝图 §五组织架构职责；课表的时间安排归教务 |
| 家长-学生绑定关系（多对多） | 平台底座（用户中心） | 2026-09-09 协调者仲裁：被家校、收费、通知、报告跨域消费的事实数据；招生与教务仅为建立渠道 |
| 站内信与公告投递 | 平台底座 | 消息中心管投递通道；家校定向触达的业务规则归家校域 |
| 文件元数据 | 平台底座 | 对象存储实体归文件服务 |
| 数据字典与参数配置 | 平台底座 | |
| 教室设备（白板注册/心跳） | 平台底座 | 设备管理，四期交付 |
| 招生线索、报名与录取记录 | 招生域 | |
| 课程/章/节/课时、知识点树、课件资源（含课时-资源包） | 课程域 | |
| 课堂记录（板书等授课产物，挂课时） | 课程域 | 2026-09-09 协调者裁定（宪法 v0.5 §4）：教师授课产物随课时归课程域；家长端回看、学生端回放、学情分析经契约消费 |
| 学习记录（进度/笔记） | 学习域 | |
| 课堂互动参与记录（点名/抢答等） | 学习域 | 2026-09-09 协调者裁定（宪法 v0.5 §4）：学生参与数据归学习过程；学情分析经契约消费 |
| 作业任务流（布置/提交状态/打回） | 学习域 | 2026-09-09 协调者仲裁：作业拆两流，任务流归学习域 |
| 题目、试卷、三形态（作业/测验/考试）的答题记录与成绩 | 测评域 | 同上仲裁：作业的答题流（答题/判分/成绩）归测评域 |
| 学情画像、成长档案、预警记录 | 学情域 | 源数据归源域，画像为衍生数据 |
| 校历课表（五要素）、考务编排、学籍（在校状态与异动）、教师工作量、教室（空间实体） | 教务域 | 教室为教务一等实体（蓝图 §十一），教室-班级常驻绑定同；教室内的设备实体归底座 |
| 通知触达记录、请假审批、沟通记录、家长会 | 家校协同域 | |
| 账单、缴费/退费记录 | 收费运营域 | 饭卡充值与代收消费账单同归本域（core v0.7） |
| 报修与事务工单、公文与审批流程 | 校园服务域 | 五期交付（core v0.7 加域）；教学设备（白板等）报修工单归底座设备管理 |

## 规则

- 归属判定有争议 → 协调者仲裁，裁定结果必须写入本文件——**同一冲突只允许发生一次**
- 域内私有数据无需登记；被跨域访问的数据实体必须登记
