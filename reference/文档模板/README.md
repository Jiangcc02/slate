## 1. 使用方式

1. 找到本次课对应的模板（见第 3 节对照表）
2. 复制到小组仓库 `docs/` 目录，按 `P{课次}-{文档类型}-{组号}.md` 重命名 例：`P01-项目立项说明书-G05.md`
3. 把 `{{...}}` 占位符替换成你的内容， **删除所有斜体提示文字**
4. 提交前对照模板末尾的「提交前自检」逐项打勾

**证据文件**（截图 / 视频）统一放 `evidence/`，命名 `P{课次}-证据-{序号}-{简述}.png`。

## 2. 小组仓库建议结构

```
{项目名}-G{组号}/
├── README.md              项目说明 + 启动步骤 + 成员
├── docs/                  全部 Markdown 交付文档
├── evidence/              截图 / 视频 / 测试报告
├── sql/                   建库脚本 + 种子数据
├── {项目名}-backend/      后端源码
└── {项目名}-frontend/     前端源码
```

> 关于分组说明：1、分组完毕不再改动。2、分组座位固定。3、分组组号划分规则：讲台面向、自右至左、自前置后，依次增1

## 6. 图表编号与标题规范（大纲格式要求，搬进报告时必须改）

大纲对综合实验报告的图表有硬性规定，Markdown 里的写作习惯与之不同，复制到 Word 报告时请按上表调整：

| 对象 | 编号格式                          | 标题位置       | 对齐   | 字体     |
|------|-----------------------------------|----------------|--------|----------|
| 图   | `图 3-2 系统 E-R 图`（章号-序号） | **在图的下方** | 居中   | 宋体五号 |
| 表   | `表 3-1 用户表结构`（章号-序号）  | **在表的上方** | 左对齐 | 宋体五号 |

其他要求

- 图形线条清晰， **尽可能不用彩色**（截图建议处理为灰度或单色）
- 表格同样尽量不用彩色，不用斑马纹
- 图 / 表超宽时，该页纸张设为横向，或缩小后分栏处理
- 正文：宋体、小四号字、1.5 倍行距
- 报告须有统一封面、目录、页码

> **结课报告例外**：P15 的结课报告为 Word 文档，使用学校统一模板，不在此目录提供 Markdown 版本。
> 撰写要求见 [T14](T14-归档清单.md) 第 3 节。
