## 3. 统一响应结构 Result\<T\>

```java
public class Result<T> {
    private Integer code;      // {{业务状态码，200 表示成功}}
    private String message;    // {{提示信息}}
    private T data;            // {{业务数据}}
    private Long timestamp;    // {{响应时间戳}}
}
```

**约定说明**

- 所有接口统一返回 `Result<T>`，前端按 `res.data` 取业务数据
- 分页数据统一放 `data` 中，含 `records / total / size / current` 字段
- 失败时 `data` 为 null，`message` 给用户可读提示
