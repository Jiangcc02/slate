> *必须证明：方法抛异常后，数据库里 **没有**留下半条数据。*

| 项         | 内容                                 |
|------------|--------------------------------------|
| 测试编号   | {{TC-00X}}                           |
| 被测方法   | {{如：OrderServiceImpl.createOrder}} |
| 触发方式   | {{在方法中手动抛 RuntimeException}}  |
| 前置数据   | {{执行前 t_order 表有 N 条记录}}     |
| 执行后数据 | {{仍为 N 条，未新增}}                |
| 关键注解   | {{@Transactional + @SpringBootTest}} |
| 证据       | {{evidence/P04-事务回滚-01.png}}     |

**这一步的意义**：如果异常后数据仍然落库，说明事务没生效——常见原因是方法非 public、同类内部调用、或异常被 try-catch 吞掉。
