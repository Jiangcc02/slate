# 课程三件套归档清单

> 适用：P16 成果③。课程要求提交「三件套」：源码 + 实验报告 + 答辩材料。
> 提交前逐项核对，确保三件套完整。
>
> **考核依据**（《软件项目开发综合实验》教学大纲六·考核方式与成绩评定办法）：
> 本模板同时承接三项考核：
> ① **期末考试·综合实验报告（占 40%，权重最高）**——§3 完整对应大纲对结课报告的全部格式与内容要求；
> ② **期末考试·答辩汇报（占 10%）**——§4 答辩材料要求与 T15 配套；
> ③ **过程性考核·阶段性成果展示（占 20%）**——§5 列出 14 项过程性文档的归档清单，覆盖大纲点名的六种阶段性成果形式。
>
> 直接复制本模板，把 `{{...}}` 替换成你的内容， **删除所有斜体提示文字后再提交**。

## 2. 源码提交要求

- [ ] 能编译运行（README 写清启动步骤）
- [ ] 数据库脚本（`.sql`）一并提交，能重建库表
- [ ] 不含本地绝对路径、不含密钥密码
- [ ] 提交的是 **最终版**（非半成品 / 空包）
- [ ] Git 提交记录完整（≥ 10 次有效 commit）
- [ ] 代码有基本注释，关键逻辑能看懂

---

## 3. 结课报告要求

> *结课报告为 Word 文档，按学校《软件项目开发综合实验模板（结课报告模板供参考）.docx》撰写。*
>
> **占期末成绩 40%，是权重最高的一项。** 大纲要求：完成系统设计的过程 + 系统基本功能 + 对实验过程进行总结。

### 3.1 内容要求

- [ ] 使用学校统一模板（含封面、目录、页码）
- [ ] 结构完整：系统分析 → 功能模块设计 → 数据库设计 → 系统实现 → AI 技术应用情况 → **总结（学校模板未含此章，需自行补写）**
- [ ] 配图为 **自己项目**的真实截图，无盗图
- [ ] 数据库设计章节含 E-R 图与主要表结构说明
- [ ] 报告为小组成员原创，查重率符合学校相关规定

### 3.2 格式要求（大纲原文，逐项核对）

| 项                 | 要求                                                                                 |
|--------------------|--------------------------------------------------------------------------------------|
| 封面 / 目录 / 页码 | 统一格式，齐全                                                                       |
| 正文               | 宋体、小四号字，行距 1.5 倍                                                          |
| 图形               | 线条清晰，尽可能不用彩色；**标题在图下方、居中**；图超宽时纸张横向或作其它处理       |
| 表格               | 宋体、五号字，尽可能不用彩色；**标题在表上方、左对齐**；表超宽时纸张横向或作其它处理 |

- [ ] 正文宋体小四、1.5 倍行距
- [ ] 所有图有编号与标题，标题在 **图下方**并居中（如：图 3-2 系统 E-R 图）
- [ ] 所有表有编号与标题，标题在 **表上方**并左对齐（如：表 3-1 用户表结构）
- [ ] 图表尽量不用彩色
- [ ] 超宽图表已做横向排版处理
- [ ] 封面、目录、页码齐全

> 提示：`docs/` 里的 Markdown 文档内容可直接搬进报告，但搬的时候请按上表调整标题位置——
> Markdown 里习惯把图注写在图上方，而大纲要求图题在图下方。
