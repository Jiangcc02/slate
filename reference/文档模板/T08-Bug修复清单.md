## 附：常见 Bug 速查（联调阶段高频）

| 现象               | 常见根因                         | 排查方向                                |
|--------------------|----------------------------------|-----------------------------------------|
| 前端报 CORS        | 后端没配 / 代理没生效            | 看 Network 里 OPTIONS 的返回            |
| 401 未登录         | token 没带 / 拦截器没放行        | 看 Request Headers 有没有 Authorization |
| 数据为空但接口 200 | 字段名大小写不符                 | 后端驼峰映射开关                        |
| 时间显示 1970      | 前端拿到秒、后端传毫秒（或反之） | 统一用毫秒时间戳                        |
| 金额精度错         | 用了 float/double                | 后端 DECIMAL，前端别做浮点运算          |
| 分页不生效         | 没配分页插件                     | MybatisPlusConfig 分页拦截器            |
| 更新后还是旧数据   | 缓存没清                         | 更新后删除缓存 key                      |
| 列表顺序乱         | 没加 ORDER BY                    | SQL 里显式排序                          |
